# Joint Statement on Slow Research / 学生“慢科研”联合倡议

中英双语声明与联署名单。

- 在线页面 / Site: https://slow-research.github.io/statement/ （需在 Settings → Pages 中选择 `main` 分支 `/ (root)` 部署）
- 来源 / Source: https://gaplab.cuhk.edu.cn/slow_research
- 加入联署 / Sign: https://gaplab.cuhk.edu.cn/slow_research/sign

## 文件 / Files

- `index.html` — 中英文切换的单页（声明 + 联署名单）
- `signatories.json` — 联署名单数据（共 120 位）。每条为数组：`[nameEn, positionEn, affiliationEn, nameZh, positionZh, affiliationZh]`；海外学者仅有前三项（中文版沿用英文）。

## 更新名单 / Updating

直接编辑 `signatories.json` 并提交即可，页面会自动渲染并更新人数。
